隱私權政策

最後更新：2026 年 3 月 27 日

Harness（以下稱「本外掛」）是一個依 Apache 2.0 授權釋出的開源 Claude Code 外掛。本隱私權政策說明 Harness 如何處理使用者資料。

簡短版說明

Harness 不會 蒐集、儲存、傳輸或分享任何個人資料。它完全在你的本地 Claude Code 環境中運作。

1. 資料蒐集

Harness 不會蒐集任何個人資訊，具體包含：

  • 不需要使用者帳號或註冊
  • 沒有任何 analytics、telemetry 或追蹤機制
  • 不使用 cookies 或 local storage 來進行追蹤
  • 不會向外部伺服器發送網路請求
  • 不會蒐集 IP 位址、裝置識別資訊或使用模式

2. 外掛如何運作

Harness 完全在 Claude Code 的執行環境內運作：

  • 它會讀取你的專案檔案，以分析領域與程式碼庫內容
  • 它會在你的本地專案目錄中產生 Markdown 檔案（例如 .claude/agents/ 與 .claude/skills/）
  • 所有處理都透過 Claude Code 內建工具在本地完成
  • 就外掛本身而言，資料不會離開你的電腦

3. 第三方服務

Harness 不會整合第三方服務，也不會主動將資料送往第三方。不過仍請注意：

  • Harness 會在 Claude Code 中執行，而 Claude Code 由 Anthropic 經營；你與 Claude Code 的互動仍受 Anthropic 隱私權政策 規範。
  • 如果你是透過 GitHub marketplace 安裝 Harness，你與 GitHub 的互動仍受 GitHub 隱私聲明 規範。

4. 生成檔案

Harness 生成的檔案（例如 agent 定義、skill 與 orchestrator 設定）都會儲存在你的本地專案目錄中。你對這些檔案擁有完整控制權，可自行修改、刪除或納入版本控制。

5. 開源透明性

Harness 完全開源。你可以直接在 github.com/revfactory/harness 查閱完整原始碼，以驗證本政策中的隱私聲明。

6. 兒童隱私

Harness 不會刻意蒐集任何人的資料，也包含 13 歲以下兒童。由於本外掛本身不蒐集任何資料，因此不存在額外的年齡相關資料處理問題。

7. 本政策的變更

若本隱私權政策未來有所調整，更新版本將發布於 GitHub repository 與本頁面中。頁首的「最後更新」日期會反映最新修訂時間。

8. 聯絡方式

若你對本隱私權政策或 Harness 外掛有任何問題，請到 github.com/revfactory/harness/issues 開 issue，或透過 GitHub 聯繫維護者。
