隱私權政策

最後更新：2026 年 7 月 14 日

資料蒐集

Harness 是在 Codex 中執行的本機外掛與技能，本專案本身不經營伺服器、不建立帳號，也不主動蒐集或傳送個人資料。

檔案與工作內容

Harness 會在使用者授權的工作區內建立或修改 AGENTS.md、.codex/agents/、.agents/skills/ 與相關專案檔案。實際可存取範圍由 Codex 的 permission mode、sandbox 與專案信任設定控制。

外部服務

Harness 核心不需要外部 API Key。若使用者選擇讓自訂代理人連接 MCP、私有 API、GitHub、Notion 或其他服務，資料處理由該服務與 Codex／ChatGPT 的相關政策規範。請只授予最小必要權限，並透過安全的憑證流程保存密鑰。

日誌與產物

Codex 工作階段、命令輸出與本機外掛快取可能由 Codex 產品保存。請依你的帳號、工作區與組織政策管理。不要把密鑰、密碼或敏感資料寫入 Git、Markdown、TOML、Issue、PR 或 _workspace/。

變更

若 Harness 未來加入自有網路服務、分析或遠端儲存，本政策會在功能發布前更新。

聯絡方式

請至 GitHub Issues 回報隱私權或安全問題，並避免在公開 issue 中附上敏感資訊。
