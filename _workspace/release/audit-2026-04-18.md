### 1.1 不一致摘要

**三重不一致狀態** —— 這是可能在 enterprise 審批與 marketplace 信任建立流程中，第一個就被淘汰的 hygiene 問題。

- README badges（3 種）vs plugin.json：**2 個版本差距**（1.0.1 → 1.2.0）
- marketplace.json vs plugin.json：**1 個版本差距**（1.1.0 → 1.2.0）
- plugin.json vs git tag：**缺少 tag**（雖然宣告為 1.2.0，但 release artifacts 為 0）

### 1.2 不一致的影響程度

| 影響面向 | 症狀 |
|----------|------|
| 可信度 | 訪客看到 README badge 後，會誤以為「1.0.1 才是最新版本」→ 先入為主地認為是舊版本 |
| 安裝體驗 | 在 marketplace 安裝時會以 1.1.0 meta 註冊，但實際 plugin 是 1.2.0 → 後續更新無法追蹤 |
| Release 追蹤 | `git tag -l` 為空 → `gh release list` 為空 → 使用者無法追蹤各版本 CHANGELOG |
| Enterprise 審批 | 若沒有 tagged release，就無法建立 CVE、SBOM 與 audit trail |
