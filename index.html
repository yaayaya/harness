開始使用 查看原始碼

從角色設計到完成驗證

Codex 自訂代理人

產生 `.codex/agents/*.toml`，明確定義責任、權限、工具、輸入與輸出。

可重複技能

以 `.agents/skills/` 建立 Orchestrator、領域知識、驗證腳本與參考資料。

多代理架構

支援 Pipeline、Fan-out、Expert Pool、Producer-Reviewer、Supervisor 與階層式委派。

單一寫入者

探索與審查預設唯讀，降低平行修改造成的衝突與不確定性。

漸進式揭露

只在需要時載入完整 Skill 與 references，讓主工作階段保持清楚。

完成證據

同時驗證結構、觸發、失敗處理、資料流與實際 Dry-run。

以 Codex 原生格式運作

專案指示`AGENTS.md`
自訂代理人`.codex/agents/*.toml`
專案技能`.agents/skills/*/SKILL.md`
外掛入口`.codex-plugin/plugin.json`

加入 Codex Marketplace

powershell -NoProfile -Command "codex plugin marketplace add yaayaya/harness-zh --ref codex"

重新啟動 ChatGPT 桌面版或 Codex，在 Plugins 中選擇 Harness Codex marketplace 並安裝 Harness。

Harness 核心不需要 OpenAI API Key。只有你建立的代理人需要連接外部 MCP 或私有 API 時，才需要另外設定憑證。
