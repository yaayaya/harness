隐私权政策

最后更新：2026 年 3 月 27 日

Harness（以下称「本外挂」）是一个依 Apache 2.0 授权释出的开源 Claude Code 外挂。本隐私权政策说明 Harness 如何处理使用者资料。

简短版说明

Harness 不会 搜集、储存、传输或分享任何个人资料。它完全在你的本地 Claude Code 环境中运作。

1. 资料搜集

Harness 不会搜集任何个人资讯，具体包含：

  • 不需要使用者帐号或注册
  • 没有任何 analytics、telemetry 或追踪机制
  • 不使用 cookies 或 local storage 来进行追踪
  • 不会向外部伺服器发送网路请求
  • 不会搜集 IP 位址、装置识别资讯或使用模式

2. 外挂如何运作

Harness 完全在 Claude Code 的执行环境内运作：

  • 它会读取你的专案档案，以分析领域与程式码库内容
  • 它会在你的本地专案目录中产生 Markdown 档案（例如 .claude/agents/ 与 .claude/skills/）
  • 所有处理都透过 Claude Code 内建工具在本地完成
  • 就外挂本身而言，资料不会离开你的电脑

3. 第三方服务

Harness 不会整合第三方服务，也不会主动将资料送往第三方。不过仍请注意：

  • Harness 会在 Claude Code 中执行，而 Claude Code 由 Anthropic 经营；你与 Claude Code 的互动仍受 Anthropic 隐私权政策 规范。
  • 如果你是透过 GitHub marketplace 安装 Harness，你与 GitHub 的互动仍受 GitHub 隐私声明 规范。

4. 生成档案

Harness 生成的档案（例如 agent 定义、skill 与 orchestrator 设定）都会储存在你的本地专案目录中。你对这些档案拥有完整控制权，可自行修改、删除或纳入版本控制。

5. 开源透明性

Harness 完全开源。你可以直接在 github.com/revfactory/harness 查阅完整原始码，以验证本政策中的隐私声明。

6. 儿童隐私

Harness 不会刻意搜集任何人的资料，也包含 13 岁以下儿童。由于本外挂本身不搜集任何资料，因此不存在额外的年龄相关资料处理问题。

7. 本政策的变更

若本隐私权政策未来有所调整，更新版本将发布于 GitHub repository 与本页面中。页首的「最后更新」日期会反映最新修订时间。

8. 联络方式

若你对本隐私权政策或 Harness 外挂有任何问题，请到 github.com/revfactory/harness/issues 开 issue，或透过 GitHub 联系维护者。
